### Hi, I'm Christian 👋

I build tools for my home server and publish the ones that might be useful
to others. Everything here is a personal hobby project — built for my own
needs first, shared in case it helps someone else.

#### 🧰 Cockpit plugin suite

A family of plain, dependency-light plugins for the
[Cockpit](https://cockpit-project.org/) web console. No build steps, no
frameworks — readable at a glance:

| Plugin | What it shows |
|--------|---------------|
| 🔗 [cockpit-tailscale](https://github.com/cgillinger/cockpit_tailscale) | Your Tailscale network in plain language — device status, actionable warnings, push alerts |
| 🌡️ [cockpit-temps](https://github.com/cgillinger/cockpit_temp) | Hardware temperature history (CPU/NVMe) with thresholds, 120 days of PCP archives |
| 💽 [cockpit-smart](https://github.com/cgillinger/cockpit_smart) | S.M.A.R.T. disk health for HDD/SSD/NVMe with history and trend detection |
| ☁️ [cockpit-pcloud](https://github.com/cgillinger/cockpit-pcloud) | pCloud storage quota, account status and backup folder health |

Browse them all via the
[`cockpit-plugin` topic](https://github.com/search?q=user%3Acgillinger+topic%3Acockpit-plugin&type=repositories).
